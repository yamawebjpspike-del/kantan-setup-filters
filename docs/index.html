広告ブロックのルール

アプリの広告ブロックが使うルールを、ここで配信しています。 毎週月曜に EasyList / EasyPrivacy の最新版から作り直しています。

  • blocklist.json — ルール本体
  • config.json — アプリの案内文と配信設定

ルールは The EasyList authors（easylist.to）の 著作物をもとにしており、CC BY-SA 3.0 のもとで配布しています。作り方は リポジトリをご覧ください。
