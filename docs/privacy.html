プライバシーポリシー

最終改定日: 2026年8月19日

〔提供者名〕（以下「当方」）は、iOS アプリ「スマホかんたんセットアップ」（以下「本アプリ」）における利用者の情報の取扱いについて、以下のとおり定めます。

1. 基本方針 — 端末の外に出しません

本アプリは、利用者の個人情報を当方のサーバーへ送信しません。 当方はサーバーを持っておらず、利用者の情報を受け取る仕組みがありません。

連絡先、メッセージの本文、支払いの控えなど、本アプリが扱う情報は、すべて利用者の iPhone または iPad の中だけで処理し、その端末の中に留まります。

広告 SDK、アクセス解析 SDK、クラッシュ報告 SDK のいずれも組み込んでいません。

2. 本アプリが扱う情報

2-1. 連絡先（許可を求めます）

  • 何を: 連絡先に登録された氏名・よみがな・電話番号
  • なぜ: 書き方のばらつきや、同じ相手の重複を点検するため
  • どこで: 端末の中だけ
  • 保存: しません。点検が終わると結果だけが画面に残り、アプリを閉じると消えます
  • 書き換え: しません。本アプリが連絡先を追加・変更・削除することはありません

許可は「設定」→「プライバシーとセキュリティ」→「連絡先」でいつでも取り消せます。

2-2. リマインダー（許可を求めます）

  • 何を: 「リマインダー」への覚え書きの作成と削除
  • なぜ: 毎月の支払日の 3 日前にお知らせするため
  • 範囲: 本アプリが作成した覚え書きだけを対象とします。利用者ご自身が書いた覚え書きの読み取り・変更・削除は行いません
  • 削除: 支払いの控えを本アプリで消したとき、対応する覚え書きも併せて削除します

2-3. 利用者が貼り付けたメッセージの本文

「これ詐欺？と調べる」で貼り付けられた文章は、端末の中だけで判定に使います。判定が終わったあと、本アプリはその文章を保存しません。外部へも送信しません。

判定には Apple の端末内蔵の言語モデル（Apple Intelligence）を使う場合があります。この処理も端末の中で完結し、Apple のサーバーへ送信されることはありません。Apple の Private Cloud Compute は使用していません。

2-4. 端末の中に保存する情報

次の情報は、利用者の端末の中にだけ保存されます。当方は参照できません。

  • 設定手順のチェック（「済ませました」の印）
  • 毎月はらっているものの控え（名前・金額・支払日・お知らせする日）
  • 広告ブロックの設定

本アプリを削除すると、これらはすべて端末から消えます。

2-5. 扱わない情報

本アプリは次の情報を扱いません。入力欄も設けません。

  • パスワード
  • クレジットカード番号・銀行口座番号
  • Apple Account（Apple ID）とそのパスワード
  • 位置情報
  • 写真・カメラ
  • マイク・通話の内容
  • 生年月日・住所などの本人確認情報

3. 外部への通信について

本アプリは、案内文と広告ブロック用のフィルタの最新版を受け取るために、GitHub Pages（GitHub, Inc.）と通信します。この通信は受け取るだけで、利用者の情報を送るものではありません。

ただし、インターネットの仕組み上、通信の相手方のサーバーには IP アドレスおよび端末の種類などの技術的な情報が記録されます。これは当方が意図して送るものではなく、あらゆるウェブ通信に共通するものですが、正確を期すため記載します。

GitHub, Inc. の取扱いについては、同社のプライバシーステートメントをご確認ください。

この通信に失敗しても、本アプリはアプリに同梱された内容で動作します。

4. 第三者への提供

当方は、利用者の情報を第三者に提供しません。そもそも当方が利用者の情報を受け取る仕組みがありません。

法令に基づく開示請求があった場合も、当方が保有していないため提供できません。

5. 情報の保存期間と削除の方法

端末内に保存された情報は、次のいずれかで削除されます。

  • 本アプリをアンインストールする
  • 本アプリの中で、控えを 1 件ずつ「消す」

連絡先とリマインダーの許可は、「設定」→「プライバシーとセキュリティ」からいつでも取り消せます。

6. お子さまの利用について

本アプリは特定の年齢層を対象とした情報収集を行いません。そもそも利用者を識別する情報を収集していません。

7. 開示・訂正・削除のご請求

個人情報の保護に関する法律に基づく開示等のご請求について、当方は利用者の個人情報を保有していないため、開示すべき情報がありません。端末内の情報は、前項の方法で利用者ご自身が削除できます。

8. 本ポリシーの変更

法令の変更や機能の追加に伴い、本ポリシーを変更することがあります。重要な変更を行う場合は、アプリ内および公開ページで告知します。
